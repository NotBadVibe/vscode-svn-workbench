AI 合并候选
async acquire(id: string) {
  const key = `order:${id}`;
  return this.remote.lock(
    key, { ttl: 5000 }
  );
}
为什么这样合并

保留仓库侧共享锁以支持多实例，同时沿用你的 5000ms 超时。建议应用后运行并发订单测试。
