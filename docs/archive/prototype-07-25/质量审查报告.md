## 三、Anti-Slop 硬性门控结果（真 grep 实测）

### 🔴 红线 1：组件样式零 hex
- **方法**：`grep #[0-9a-fA-F]{3,6}` 对 11 文件全量扫描。
- **结果**：✅ **PASS**。所有 hex 命中**仅位于 `:root` 离线预览兜底块**（如 `提交拆分队列` 22–78 行、`提交面板` 85–132 行、`冲突中心` 82–130 行），组件样式段**零 hex**。
- **证据**：`提交拆分队列.html` 共 57 处 hex 全部在 `:root`；`提交面板`/`冲突中心` 同构。

### 🔴 红线 2：禁用 innerHTML 拼接
- **方法**：`grep innerHTML` 全量扫描。
- **结果**：✅ **PASS**。命中均为注释声明「禁用 innerHTML 拼接」（如 `提交面板:10,1215`、`冲突中心:740`、`环境检查:563`、`范围与筛选:1296`），**无任何 `.innerHTML =` 赋值或字符串拼接**。脚本均为 `textContent` / `classList` / `setAttribute` / `createElement` 受控渲染。

### 🔴 红线 3：成功色统一 `--color-success-fg`
- **方法**：`grep color-success-fg` + `grep vscode-testing-`。
- **结果**：✅ **PASS**。所有「成功/就绪/通过」语义一律 `var(--color-success-fg)`（如 `环境检查:249,266,273,296,307`、`验收清单:289,547`、`范围与筛选:367,372,462,650`、`提交拆分队列:270,273,277,302,305,394,398`）。**无 `vscode-testing-iconPassed` 或其他绿色误用**（grep 0 命中）。

### 🔴 红线 4：无 `prefers-color-scheme` 浅色硬编码
- **方法**：`grep prefers-color-scheme` 全量。
- **结果**：✅ **PASS**。**0 命中**。深浅同源自动适配，无浅色硬编码分支。

### 🔴 红线 5：两处降级分支真实存在且可触发
- **方法**：`grep` 降级卡 id / class + `@media` + 演示开关接线。
- **结果**：✅ **PASS**。两处降级分支齐全且可触发：
  - **svn 缺失引导卡**（指向 `svnWorkbench.svn.path`，不静默退出）：`提交差异摘要#svnCard`、`提交拆分队列#svnCard`、`提交面板#svnGate`、`冲突中心[data-svn-gate]`、`更新建议[gate-card--svn]`、`范围与筛选#svnGate`、`验收清单#svnGate`。
  - **AI 未配置手动模式卡**（info 左条，不抛错）：`提交拆分队列#aiInfoCard`、`提交拆分预览#aiInfoCard`、`团队规则配置#aiInfoCard`、`提交面板#aiNotConfigured`、`更新建议[gate-card--ai]`、`范围与筛选#aiGate`、`验收清单#aiGate`。
  - 均由 DemoBar（`demoSvn`/`demoAi`/`data-demo`）或 `applyState({svnMissing,aiConfigured})` 接入点真实切换 `hidden`，非死代码。
- **`@media`** 仅断点（`max-width:720px` ×4、`640px` ×1），无色彩硬编码。

### 🟡 辅助红线：裸几何值（非令牌 px）
- **方法**：`grep :\s*\d+px[;)\s]` 对组件段（行号 > `:root` 末尾）扫描。
- **结果**：⚠️ **P1/P2 级偏差**（不构成发布阻断）：

  - **已确认属允许例外**：`outline:1px solid var(--color-focus)`（focus 描边，多文件）、`border-left:4px solid var(--color-*)`（4px 左条，冲突中心 239/367/368、提交拆分队列 `--bar-thickness:4px`）。

## 四、重点弱区核查结论

### 弱区 1 · 提交拆分队列.html（NextAction / 阻止项 / 双维状态）
✅ **全部达标，且为 11 页中最严谨实现**
- **NextAction 十态**：`NA_STATES` 恰好 10 项（`empty / waitBulkPreview / reviewBlocked / retryFailed / previewFailed / submitReady / previewNotPreviewed / waitSubmitting / allDone / idle`），每项含 `sem`(success/warning/info) + `icon` + `title` + `detail` + 单一 `btn`；`renderNextAction` 对无 `btn` 态执行 `naBtn.hidden = true`，**单一主操作被强制保证**，零歧义。
- **七类阻止项**：`data-cat` 七值齐全 `scope / candidate / excluded / blocked / svnStatus / emptySelection / unknown`；其中 `svnStatus` 带 `is-error` 类（error 语义左条），其余 warning 左条；分类筛选 `filterCat` 可过滤七卡。
- **双维状态徽标**：队列行 `status × planStatus` 双类（`q-status--pending/applied/submitting/completed/failed` + `q-plan--notPreviewed/ready/blocked`），配合 `data-status`/`data-plan` 双维筛选，零歧义。
- **优先级逻辑**：`computeNextAction` 采用 `failed > blocked > ready > notPreviewed > allDone > idle`，符合「先解决阻断再提交」的域语义。

### 弱区 2 · 提交差异摘要.html（svn 缺失降级 / 增删色 / 截断）
✅ **全部达标**
- **svn 缺失「关键不静默」**：`#svnCard`（`info-card error`，error 左条）默认 `hidden`，由 `demoSvn` 切换；引导文案明确指向 `svnWorkbench.svn.path`，不静默退出、不阻断其他区块（同屏 StatusSummary/DiffFileList 同步 `hidden`）。
- **增删色严格**：逐文件状态与错误行 `is-error` 均走 `--color-diff-add-fg` / `--color-diff-del-fg`（严格语义色，未混用 generic green/red）。
- **>80 文件截断**：`truncNote` 存在且受控显隐（`hidden = !truncated || svnMissing || empty`），DemoBar `truncated` 开关可演示。

### 弱区 3 · 命令孤岛 / NextAction 连贯性（跨页串联）
✅ **连贯无断点**
- 全 11 页共享同一 `:root` 令牌集 + 统一 inline SVG `<symbol>` 符号表 + 统一降级组件（`gate-card` / `info-card`）+ 统一语义色规范，视觉语言零漂移。
- **ScopeBar 连续性**：拆分队列 / 拆分预览 / 范围与筛选 / 提交面板 / 差异摘要 均含范围上下文顶栏，路径与「右键文件夹」范围一致。
- **NextAction 引导连贯**：拆分队列以其十态横幅为锚；拆分预览以 `PlanStatusBar`（ready/blocked）承接；更新建议以 `InfoBanner`（近似建议声明）衔接；环境检查以状态卡（`ok/warning/error`）兜底。链路 **AI配置 → 团队配置 → 拆分 → 预览 → 差异** 的引导语义一致，无孤岛。
