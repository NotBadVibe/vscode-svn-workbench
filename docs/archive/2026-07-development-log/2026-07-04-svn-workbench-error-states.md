# SVN Workbench 错误状态与恢复交互设计

> 产品暂名：SVN Workbench for VS Code / SVN 工作台  
> 文档类型：设计阶段错误状态规格  
> 编写日期：2026-07-04  
> 当前阶段：设计阶段  
> 适用平台：Windows / macOS 标准统一  
> 文档策略：新增文件，不覆盖旧文档

## 1. 文档目标

定义 SVN Workbench 中所有主要错误状态的展示、恢复动作、诊断信息和验收规则。

错误设计目标：

- 用户知道发生了什么。
- 用户知道可能为什么发生。
- 用户知道下一步能做什么。
- 开发者能拿到可诊断信息。
- 敏感信息不泄露。
- Windows/macOS 体验统一。

## 2. 错误提示统一结构

所有错误提示必须包含三层信息：

```text
发生了什么
为什么可能发生
建议下一步
```

示例：

```text
提交失败：远端已有更新

当前文件不是最新版本，可能有人已经提交了相关修改。

建议先更新当前范围，解决可能的冲突后再提交。
```

按钮：

```text
更新并继续
查看远端更新
打开输出
```

## 3. 错误展示层级

### 3.1 轻提示 Notification

用于：

- 操作成功。
- 非阻塞警告。
- 后台刷新失败但不影响当前编辑。

示例：

```text
SVN 状态刷新失败，可稍后重试。
```

### 3.2 页面内错误 Inline Error

用于：

- 提交页检查失败。
- AI 输出无法解析。
- 当前范围无效。
- 表单配置错误。

### 3.3 模态确认 Modal

用于：

- 危险操作确认。
- 需要用户明确选择恢复路径。
- 认证失败需要换账号。

### 3.4 Output Channel

用于：

- 原始 SVN 命令输出。
- 原始 AI 调用错误。
- 解析失败详情。
- 脱敏诊断。

## 4. 错误数据模型

### 4.1 AppError

```ts
interface AppError {
  code: string;
  severity: 'info' | 'warning' | 'error' | 'fatal';
  title: string;
  userMessage: string;
  possibleReason?: string;
  recoverActions: RecoverAction[];
  diagnostic: DiagnosticInfo;
  source: 'svn' | 'ai' | 'filesystem' | 'vscode' | 'platform' | 'validation';
}
```

### 4.2 RecoverAction

```ts
interface RecoverAction {
  id: string;
  label: string;
  kind: 'primary' | 'secondary' | 'danger';
  command: string;
}
```

### 4.3 DiagnosticInfo

```ts
interface DiagnosticInfo {
  command?: string;
  cwd?: string;
  exitCode?: number;
  stdout?: string;
  stderr?: string;
  durationMs?: number;
  repositoryId?: string;
  operationScopeId?: string;
  sanitized: boolean;
}
```

## 5. SVN 环境错误

### 5.1 未找到 SVN 命令

标题：

```text
未找到 SVN 命令
```

说明：

```text
SVN Workbench 需要本机安装 SVN 命令行工具。
```

可能原因：

- 未安装 SVN。
- SVN 未加入 PATH。
- 用户配置的 SVN 路径无效。

按钮：

```text
重新检测
手动选择
查看安装说明
```

Windows 补充说明：

```text
Windows 上可以安装 TortoiseSVN、SlikSVN 或 VisualSVN command line tools。
```

macOS 补充说明：

```text
macOS 上可以通过 Homebrew 安装 Subversion，或手动选择 svn 可执行文件。
```

## 22. 诊断与脱敏

### 22.1 复制诊断内容

诊断包含：

- 扩展版本。
- VS Code 版本。
- 操作系统。
- SVN 版本。
- 命令名称。
- 工作目录。
- 退出码。
- 耗时。
- 脱敏 stdout。
- 脱敏 stderr。
- OperationScope 摘要。

### 22.2 必须脱敏

必须隐藏：

- 密码。
- API Key。
- token。
- Authorization 头。
- 用户选择隐藏的用户名。
- 敏感文件内容。

### 22.3 复制成功

```text
诊断信息已复制，敏感内容已脱敏。
```

## 23. 错误恢复优先级

恢复按钮排序：

1. 最推荐恢复动作。
2. 查看详情或打开输出。
3. 取消或关闭。

示例：

危险恢复动作不放首位，除非用户明确进入危险操作流程。

## 28. 当前设计决策

1. 错误提示统一使用“发生了什么、为什么、下一步”结构。
2. 用户提示中文化，原始诊断进入 Output Channel。
3. 所有诊断复制必须脱敏。
4. 范围越界、冲突、他人锁定、AI 不安全输出属于阻止项。
5. AI 失败不影响 SVN 基础功能。
6. Windows/macOS 错误体验统一，平台差异只体现在安装提示和外部工具名称。
