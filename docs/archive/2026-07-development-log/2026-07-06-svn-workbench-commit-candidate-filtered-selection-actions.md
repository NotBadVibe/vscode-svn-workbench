# SVN Workbench 提交候选当前筛选批量选择

日期：2026-07-06

阶段：开发 -> 测试

## 背景

提交页面已经具备搜索、SVN 状态、文件类型、模板预设、AI 建议和隐藏生成物筛选。
但用户筛选出目标文件后，仍需要逐个勾选，或者切换到分组后再按组操作。

本轮新增“当前筛选结果批量选择”，让筛选条件本身变成可直接操作的选择范围。

## 页面入口

提交页面 -> 候选文件工具栏：

- `只选当前筛选`
- `加入当前筛选`
- `移除当前筛选`

这些按钮和现有筛选条件联动：

- 搜索路径
- SVN 状态
- 文件类型
- 模板预设
- AI 建议
- 隐藏生成物

## 操作说明

`只选当前筛选`：

- 清空当前勾选。
- 只勾选当前筛选结果中的可提交文件。
- 适合先按文件类型或模板预设筛出目标范围，再快速形成提交集合。

`加入当前筛选`：

- 保留现有勾选。
- 把当前筛选结果中的可提交文件追加到勾选集合。
- 适合分多次筛选组合提交范围。

`移除当前筛选`：

- 保留其他勾选。
- 从勾选集合中移除当前筛选结果中的可提交文件。
- 适合先大范围选择，再排除某类文件。

## 可选文件规则

批量选择只会处理：

- 非默认排除项。
- 非阻止项。
- 当前筛选结果中可进入提交计划的文件。

不会批量勾选：

- 生成物排除项。
- 冲突、阻塞、异常状态文件。
- 当前筛选条件外的文件。

## 与中国式日常操作习惯的关系

常见用法：

1. 按 `文件类型 = vue`，点击 `只选当前筛选`。
2. 按 `模板预设 = 配置`，点击 `加入当前筛选`。
3. 关闭隐藏生成物检查是否有误入项。
4. 按 `AI 建议 = 排除`，点击 `移除当前筛选`。
5. 再预览提交计划。

这比逐个勾选更适合日常“先筛范围，再做批量动作”的使用习惯。

新增核心工具：

- `filterCommitCandidates`
- `getSelectableCommitCandidatePaths`

Webview 新增：

- `applyVisibleCandidateSelection`
- `getVisibleSelectableCandidatePaths`
- 工具栏三个批量选择按钮

## 跨平台一致性

该能力运行在 TypeScript 核心逻辑和 VS Code Webview 中，不依赖平台命令。
Windows 和 macOS 上的筛选规则、批量选择规则和安全边界一致。
