## 本轮新增测试

### returns selectable commit candidate group paths only

验证分组级批量操作的安全边界：

- `selected / 已选` 文件可以进入分组可选路径。
- `needsReview / 待确认` 文件可以进入分组可选路径。
- `excluded / 已排除` 文件不会进入分组可选路径。
- `blocked / 已阻止` 文件不会进入分组可选路径。
