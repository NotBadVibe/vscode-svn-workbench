# SVN Workbench AI 拆分建议队列

日期：2026-07-05

阶段：开发 -> 测试

## 目标

上一轮已经支持对单条 AI 拆分建议进行提交计划预览。本轮继续推进“拆分建议队列”。

目标是让用户把多条 AI 拆分建议先加入待提交队列，逐条预览、套用、移除，而不是在建议列表里反复查找。

## 页面变化

AI 拆分提交建议卡片新增按钮：

- `加入队列`

提交页新增区域：

- `拆分待提交队列`

队列项支持：

- `预览计划`
- `套用`
- `移除`

队列整体支持：

- `清空队列`

## 交互规则

### 1. 加入队列

点击拆分建议卡片上的 `加入队列` 后：

- 将该建议加入待提交队列。
- 如果队列里已经有相同文件集合的建议，则不会重复加入。
- 队列项初始状态为 `待处理`。

### 2. 预览计划

点击队列项的 `预览计划` 后：

- 不修改当前勾选。
- 不修改提交说明。
- 后端仍然调用提交计划预览。
- 展示 `svn add / svn remove / svn commit` 计划、风险和阻止项。

### 3. 套用

点击队列项的 `套用` 后：

- 当前勾选切换为该队列项文件。
- 提交说明填入该建议草稿。
- 队列项状态变为 `已套用`。
- 用户仍需预览计划和确认提交。

### 4. 移除

点击 `移除` 后：

- 只移除当前队列项。
- 不影响当前勾选。
- 不影响提交说明。

### 5. 清空队列

点击 `清空队列` 后：

- 移除全部队列项。
- 不影响当前勾选。
- 不影响提交说明。

## 安全边界

拆分建议队列不执行 SVN 命令。

安全链路仍然是：

1. AI 只生成建议。
2. 加入队列只保存建议。
3. 预览计划走后端提交计划校验。
4. 套用只改变勾选和提交说明。
5. 提交仍需远端更新检查。
6. 提交仍需用户最终确认。

## 下一步建议

下一步可以继续推进“队列逐条提交守护”：

- 队列项套用后强制先预览计划。
- 提交成功后自动刷新 SVN 状态。
- 成功项从队列移除或标记完成。
- 下一个队列项需要用户手动确认后再继续。
