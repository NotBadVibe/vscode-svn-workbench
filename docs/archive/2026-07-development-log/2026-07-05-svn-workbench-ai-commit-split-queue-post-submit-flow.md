# SVN Workbench AI 拆分队列提交后处理体验

日期：2026-07-05

阶段：开发 -> 测试

整体进度：约 62%

## 本轮目标

上一轮已经完成队列项 `提交此项`。本轮继续优化提交后的队列工作体验：

- 队列头部展示状态统计。
- 支持隐藏 `已完成` 队列项。
- 提交成功后自动提示下一条待处理项。
- 提交失败后保留失败项，并提示重新预览或重试。
- 清空队列或移除活动项时同步清理 active 状态，避免旧队列 ID 影响后续普通提交。

## 页面变化

拆分队列头部新增统计：

- 总数
- 待处理
- 待提交
- 提交中
- 失败
- 已完成
- 已隐藏

新增开关：

- `隐藏已完成`

当开启后：

- `已完成` 队列项不再显示。
- 统计仍保留已完成数量。
- 如果全部队列项都被隐藏，页面提示可取消隐藏查看。

## 提交成功后的提示

队列项提交成功后：

- 当前队列项标记为 `已完成`。
- 记录 revision。
- 页面提示下一条待处理项。

下一条定位规则：

- 从刚完成的队列项之后开始查找。
- 跳过 `已完成`。
- 跳过 `提交中`。
- 如果后面没有可处理项，则从队列前面继续查找。
- 如果没有任何可处理项，则提示队列已处理完。

## 提交失败后的提示

队列项提交失败后：

- 当前队列项标记为 `失败待处理`。
- 记录失败原因。
- 页面提示用户先重新预览计划。
- 状态确认后可以继续点击 `提交此项` 重试。

## 安全边界

本轮仍然不做自动提交下一条。

系统只提示下一条队列项，不会自动执行：

- 自动预览
- 自动套用
- 自动提交

用户仍需手动确认每一条队列项，SVN 命令执行前仍保留 VS Code 二次确认。

## 下一步建议

下一步可以推进“队列项重试与完成项管理”：

- `失败待处理` 队列项提供更明确的 `重新预览` / `重试提交` 分离按钮。
- `已完成` 队列项支持批量清理。
- 队列头部支持只看失败项。
- 提交完成后可选自动开启 `隐藏已完成`。
