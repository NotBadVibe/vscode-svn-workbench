# SVN Workbench 更新预览风险提示

日期：2026-07-06

阶段：开发 -> 测试

## 背景

更新预览已经能展示本地未提交摘要和远端变更摘要。
但用户仍需要自己判断本地与远端是否存在同一路径重叠、当前范围是否有阻止项，以及更新前是否需要先处理异常。

本轮新增“更新风险提示”，把本地和远端摘要合并成更新前决策建议。

## 页面入口

提交页面 -> `预览更新`

新增展示：

- 更新风险等级：低 / 中 / 高
- 同路径重叠数量
- 风险建议
- 前 8 条重叠路径

## 风险分级

高风险：

- 远端变更与本地未提交存在同路径重叠。
- 当前范围存在阻止项。

中风险：

- 远端检查失败，无法确认远端状态。
- 本地和远端都存在变化，但没有同路径重叠。
- 当前范围存在待确认项。

低风险：

- 没有明显本地和远端冲突信号。

## 示例

```text
更新风险: 高
同路径重叠: 1
建议:
- 远端与本地未提交存在 1 个同路径重叠，建议先查看差异或提交本地改动。
重叠路径:
- src/order.ts
```

## 安全边界

风险提示只做分析：

- 不阻止用户更新。
- 不自动提交。
- 不自动解决冲突。
- 不修改工作区文件。
- 不替用户选择保留本地或远端。

真正更新仍需用户点击 `更新当前范围` 并确认。

## 核心实现

新增核心能力：

- `UpdateScopeRiskLevel`
- `UpdateScopeRiskSummary`
- `summarizeUpdateScopeRisk`

扩展：

- `UpdateScopePreview.risk`

Webview 新增：

- `formatUpdateRiskSummary`

## 跨平台一致性

风险判断基于归一化路径、候选文件状态和远端状态摘要。
Windows 和 macOS 使用同一套规则。
