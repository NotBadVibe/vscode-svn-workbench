# VSCode SVN 管理器页面级功能规格说明

> 文档类型：开发落地细节规格  
> 编写日期：2026-07-04  
> 关联文档：`docs/product-spec.md`  
> 版本策略：本文件为新增文档，不覆盖上一版。后续每次调整文档都新增一个文件。

## 1. 文档目标

这份文档把 SVN 管理器拆到每个页面、入口、按钮、筛选器、状态和操作范围，作为开发时的 UI 与功能验收依据。

重点解决以下细节：

- 右键某个文件夹时，只提交这个文件夹范围内的内容。
- 提交页面支持按文件状态、文件类型、路径、后缀、大小、锁、冲突、changelist 筛选。
- 提交模板不只是填提交信息，也可以联动文件筛选预设。
- 筛选只能在当前操作范围内缩小或建议选择，不能悄悄扩大到整个工作区。
- 每个页面都要有空状态、加载状态、错误状态、取消操作和诊断入口。

## 2. 全局术语

| 术语 | 定义 |
| --- | --- |
| 工作副本 | 包含 `.svn` 元数据的本地目录 |
| 仓库根 | `svn info` 返回的 Repository Root |
| 当前 URL | 当前工作副本目录对应的 SVN URL |
| 操作范围 | 本次操作允许影响的文件集合边界 |
| 提交范围 | 提交页面中本次可提交的候选文件集合 |
| 候选文件 | 在操作范围内，经过 SVN status 扫描后可被展示的文件 |
| 已勾选文件 | 用户最终选择要参与提交、更新、还原等操作的文件 |
| 模板预设 | 提交信息模板 + 文件筛选建议 + 提交前检查规则 |
| 提交篮 | 用户为一次提交临时收集的文件列表 |

## 3. 全局操作范围规则

操作范围是所有页面的第一优先级规则。任何筛选、模板、搜索、全选都不能突破操作范围。

| 入口 | 操作范围 |
| --- | --- |
| 右键单个文件提交 | 仅该文件 |
| 右键单个文件夹提交 | 该文件夹及其子目录内的文件 |
| 右键多个文件/文件夹提交 | 多个路径范围的并集 |
| SCM 面板点击提交 | 当前仓库内全部变更 |
| SCM 面板勾选若干文件后提交 | 仅勾选文件 |
| 命令面板 `SVN: 提交当前文件` | 当前编辑器文件 |
| 命令面板 `SVN: 提交当前文件夹` | 当前资源管理器选中文件夹 |
| 命令面板 `SVN: 提交工作区` | 当前工作副本内全部变更 |
| 从提交篮打开 | 提交篮中已有文件集合 |

### 3.1 右键文件夹提交的强规则

当用户在资源管理器中右键 `src/pages/order` 并选择 `SVN: 提交 Commit`：

- 只扫描 `src/pages/order` 目录及其子目录。
- 不展示 `src/pages/user`、`src/common`、项目根目录下的其他变更。
- 文件类型筛选、模板预设、搜索、全选都只作用在 `src/pages/order` 范围内。
- 页面顶部必须显示范围提示：`范围：src/pages/order 及其子目录`。
- 提交成功后只刷新当前范围和 SCM 全局状态计数。
- 如果该目录不是工作副本的一部分，提示选择 SVN 工作副本根目录。
- 如果该目录下面有嵌套工作副本，默认不跨工作副本提交，展示提示：`检测到嵌套 SVN 工作副本，已默认排除`。

### 3.2 嵌套工作副本与 externals

默认规则：

- `svn:externals` 默认排除在提交范围外。
- 嵌套 `.svn` 工作副本默认排除。
- 页面提供开关 `显示 externals`，打开后只显示，不默认勾选。
- 若用户手动勾选 externals 文件，提交前二次确认。

### 3.3 范围不扩大原则

以下操作不能扩大范围：

- 点击 `全选`。
- 切换提交模板。
- 选择文件类型筛选。
- 清空搜索条件。
- 切换 `显示未版本控制文件`。
- AI 推荐文件。

示例：

用户右键 `assets/icons` 提交，选择模板 `前端页面` 后，模板只能在 `assets/icons` 中筛出匹配文件，不能把 `src/views` 的文件带进来。

## 4. 全局筛选层级

提交页面和变更页面采用固定筛选顺序：

```text
入口操作范围
  -> SVN 状态扫描
  -> 系统安全排除规则
  -> 用户项目排除规则
  -> 当前页面筛选器
  -> 模板预设筛选
  -> 用户手动勾选
```

### 4.1 系统安全排除规则

默认不展示或不默认勾选：

- `.svn/**`
- `.git/**`
- `node_modules/**`
- `dist/**`
- `build/**`
- `out/**`
- `target/**`
- `.env`
- `.env.*`
- `*.key`
- `*.pem`
- `*.pfx`
- `*.log`
- `*.tmp`

规则说明：

- 这些规则可在设置中调整。
- 敏感文件即使展示，也不默认勾选。
- 用户手动勾选敏感文件时，提交前弹出确认。

### 4.2 用户项目排除规则

用户可在设置或页面中配置：

- 排除文件夹。
- 排除后缀。
- 排除 glob。
- 排除大文件阈值。
- 排除生成文件规则。

页面需要显示排除摘要：`已根据过滤规则隐藏 12 个文件`，点击可查看明细。

### 4.3 页面筛选器

页面筛选器只影响可见列表和批量勾选，不直接删除候选文件。

筛选器包括：

- 状态筛选。
- 文件类型筛选。
- 路径筛选。
- 后缀筛选。
- 大小筛选。
- 时间筛选。
- 锁状态筛选。
- 冲突状态筛选。
- changelist 筛选。
- 搜索框。

### 4.4 模板预设筛选

模板预设可以做两件事：

- 填入或切换提交信息模板。
- 应用文件筛选建议。

默认行为：

- 切换模板时不直接取消用户已手动勾选的文件。
- 如果模板带筛选规则，弹出轻提示：`是否按“前端页面”模板筛选文件？`
- 用户可选：
  - `应用筛选并保留手动勾选`
  - `仅显示匹配文件`
  - `只填提交信息`

## 5. 全局页面组件

### 5.1 顶部仓库条

所有 SVN 页面顶部展示：

- 仓库名称。
- 当前 SVN URL。
- 当前修订号。
- 当前分支/路径识别结果。
- 工作副本根目录。
- 远端状态：未知、已同步、有新提交、检查失败。
- 操作范围。

交互：

- 点击 URL 可复制。
- 点击工作副本根可在资源管理器中定位。
- 点击远端状态可刷新远端检查。
- 点击操作范围可打开范围详情。

### 5.2 状态摘要条

展示当前页面的数量：

- 修改。
- 新增。
- 删除。
- 缺失。
- 冲突。
- 未版本控制。
- 锁定。
- externals。
- 已勾选。

每个数字都是可点击筛选标签。

### 5.3 批量操作条

当用户勾选文件后出现：

- 勾选数量。
- 总大小。
- 按状态统计。
- `提交`
- `还原`
- `加入忽略`
- `移动到 changelist`
- `清空选择`

危险操作需要二次确认。

### 5.4 诊断入口

每个页面右上角有 `更多` 菜单：

- 显示 SVN 输出。
- 复制诊断信息。
- 重新扫描当前范围。
- 打开设置。
- 打开文档。

## 6. 页面一：首次启动与环境检测页

### 6.1 触发时机

- VS Code 启动后未找到 `svn`。
- 用户打开非 SVN 工作区。
- 用户执行 `SVN: 检查环境`。

### 6.2 页面信息

显示卡片：

- SVN 命令行状态。
- 工作副本状态。
- 当前工作区路径。
- 已配置的 SVN 路径。
- 推荐安装方式。

### 6.3 功能

| 功能 | 说明 |
| --- | --- |
| 自动检测 | 检测 PATH、常见安装目录、TortoiseSVN bin、SlikSVN |
| 手动选择 svn.exe | 打开文件选择器，保存到设置 |
| 测试命令 | 执行 `svn --version --quiet` |
| 打开安装说明 | 打开内置帮助页 |
| 重新检测 | 刷新环境状态 |

### 6.4 状态

- 成功：显示版本号，如 `Apache Subversion 1.14.5`。
- 失败：显示错误原因和下一步按钮。
- 路径无效：提示重新选择。
- 权限不足：提示以普通用户安装或配置 PATH。

## 7. 页面二：检出 Checkout 向导

### 7.1 入口

- 命令面板 `SVN: 检出 Checkout`。
- 空工作区欢迎页。
- 资源管理器右键目标文件夹。

### 7.2 步骤

1. 输入仓库 URL。
2. 选择本地目录。
3. 选择检出深度。
4. 选择认证方式。
5. 测试连接。
6. 开始检出。
7. 打开项目。

### 7.3 字段

| 字段 | 规则 |
| --- | --- |
| SVN URL | 支持 `http`、`https`、`svn`、`file` |
| 本地目录 | 若目录非空，提示确认 |
| 项目名 | 默认从 URL 最后一段生成 |
| 检出深度 | infinity、immediates、files、empty |
| 用户名 | 可选，从凭据管理读取 |
| 密码 | 可选，SecretStorage 保存 |

### 7.4 便捷操作

- 最近 URL 下拉。
- 最近目录下拉。
- 从剪贴板识别 SVN URL。
- 测试连接成功后自动读取仓库根和最新修订号。
- 检出完成后提供 `在当前窗口打开`、`新窗口打开`。

## 8. 页面三：SVN 工作台总览

### 8.1 页面目的

让用户打开 SVN 图标后第一眼知道：当前在哪个仓库、有多少改动、有没有冲突、远端有没有新提交、是否需要更新。

### 8.2 页面布局

顶部：仓库条。  
中部：状态卡片。  
底部：最近操作和快捷入口。

### 8.3 状态卡片

| 卡片 | 内容 | 点击行为 |
| --- | --- | --- |
| 本地变更 | 修改、新增、删除、缺失数量 | 进入变更页 |
| 待处理冲突 | 冲突文件数量 | 进入冲突中心 |
| 远端更新 | 新提交数量或未知 | 进入更新页 |
| 锁定文件 | 自己锁定和他人锁定数量 | 进入锁管理 |
| 当前分支 | trunk/branch/tag 识别 | 打开切换分支 |
| 最近提交 | 最后 5 条日志 | 打开历史页 |

### 8.4 快捷按钮

- `更新工作区`
- `提交变更`
- `查看日志`
- `扫描冲突`
- `清理工作副本`
- `检出新项目`

### 8.5 空状态

非 SVN 工作区：

- 显示 `当前文件夹不是 SVN 工作副本`。
- 按钮：`检出项目`、`选择 SVN 根目录`、`打开已有工作副本`。

## 9. 页面四：变更页

### 9.1 页面目的

作为 SCM 面板的增强版，集中展示当前工作副本的所有变更。

### 9.2 分组

默认分组：

- 冲突。
- 已修改。
- 已新增。
- 已删除。
- 缺失。
- 未版本控制。
- 属性变更。
- externals。
- 忽略文件。

可切换分组：

- 按目录分组。
- 按文件类型分组。
- 按 changelist 分组。
- 按修改时间分组。

### 9.3 文件行字段

| 字段 | 说明 |
| --- | --- |
| 复选框 | 加入提交篮 |
| 状态图标 | M/A/D/!/C/?/L |
| 文件名 | 显示 basename |
| 相对路径 | 显示相对工作副本路径 |
| 文件类型 | 后缀或分类 |
| 大小 | 对新增和未版本控制文件显示 |
| 锁状态 | 自己锁、他人锁、未锁 |
| changelist | 如果存在则显示 |

### 9.4 行操作

- 打开文件。
- 打开差异。
- 加入提交篮。
- 还原。
- 加入忽略。
- 查看历史。
- 锁定/解锁。

### 9.5 变更页筛选

与提交页共用筛选器，但变更页默认不隐藏未勾选文件。

常用筛选按钮：

- `仅冲突`
- `仅未版本控制`
- `仅当前文件夹`
- `仅我锁定`
- `排除生成目录`

## 10. 页面五：提交 Commit 页面

提交页面是核心页面，必须开发到足够细。

### 10.1 入口与范围

| 入口 | 默认标题 | 默认范围 |
| --- | --- | --- |
| 右键文件 | 提交文件 | 当前文件 |
| 右键文件夹 | 提交文件夹 | 当前文件夹及子目录 |
| SCM 标题提交 | 提交工作区变更 | 当前工作副本全部变更 |
| 变更页提交篮 | 提交已选择文件 | 提交篮文件 |
| 命令面板提交当前文件 | 提交当前文件 | 当前编辑器文件 |

页面打开时必须显示：

```text
提交范围：src/pages/order 及其子目录
候选文件：12 个
已勾选：8 个
```

### 10.2 右键文件夹提交详细规则

右键文件夹后：

- 使用该文件夹作为扫描根。
- 调用 `svn status --xml <folderPath>`。
- 展示路径必须全部在该文件夹内。
- 文件夹外的本地变更不参与候选文件计数。
- 文件夹外的冲突可在顶部显示全局提醒，但不能阻止当前文件夹提交，除非当前提交范围内有冲突。
- 文件夹内直接删除的版本文件以 `缺失 missing` 展示。
- 文件夹内未版本控制文件根据设置决定是否显示，默认显示但不自动勾选。
- 若用户点击 `查看工作区其他变更`，跳转变更页，不改变当前提交页面范围。

### 10.3 页面布局

左侧：文件选择区。  
右侧：差异预览区。  
底部：提交信息区。  
顶部：范围、检查、筛选、模板。

建议比例：

- 文件选择区 35%。
- 差异预览区 65%。
- 提交信息区固定在底部，可折叠。

### 10.4 顶部工具栏

按钮和控件：

- `刷新`
- `检查远端`
- `更新并继续`
- `模板`
- `筛选`
- `全选可提交`
- `清空选择`
- `仅显示已勾选`
- `显示被过滤文件`
- `更多`

顶部状态：

- 远端状态。
- 冲突状态。
- 敏感文件提醒。
- 大文件提醒。
- externals 提醒。

### 10.5 文件列表列定义

| 列 | 是否默认显示 | 说明 |
| --- | --- | --- |
| 选择 | 是 | 复选框 |
| 状态 | 是 | M/A/D/!/C/? |
| 文件名 | 是 | 文件名 |
| 路径 | 是 | 相对路径 |
| 类型 | 是 | 分类，如 TS、Vue、图片 |
| 大小 | 是 | 新增和未版本控制文件重点显示 |
| 修改时间 | 否 | 可在列设置开启 |
| 锁 | 是 | 锁定图标 |
| 模板匹配 | 否 | 显示被哪个模板命中 |

### 10.6 文件状态筛选

状态筛选以多选标签呈现：

- `已修改 M`
- `已新增 A`
- `已删除 D`
- `缺失 !`
- `冲突 C`
- `未版本控制 ?`
- `属性变更`
- `锁定`
- `externals`

默认：

- 显示 M/A/D/!/C/?。
- `冲突 C` 显示但不可提交，必须先解决。
- `未版本控制 ?` 显示但不默认勾选。
- `externals` 默认隐藏。

### 10.7 文件类型筛选

文件类型筛选是提交页高频功能，必须显眼。

默认类型分类：

| 类型 | 后缀 |
| --- | --- |
| 前端源码 | `.js`、`.jsx`、`.ts`、`.tsx`、`.vue`、`.svelte` |
| 样式 | `.css`、`.scss`、`.less`、`.sass`、`.styl` |
| 后端源码 | `.java`、`.kt`、`.cs`、`.go`、`.py`、`.php`、`.rb` |
| 配置 | `.json`、`.yaml`、`.yml`、`.xml`、`.ini`、`.properties`、`.toml` |
| 文档 | `.md`、`.txt`、`.docx`、`.xlsx`、`.pdf` |
| 图片 | `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.svg`、`.ico` |
| 数据库 | `.sql`、`.db`、`.sqlite` |
| 脚本 | `.sh`、`.bat`、`.cmd`、`.ps1` |
| 二进制 | 无法文本 diff 或常见二进制格式 |
| 其他 | 未归类 |

交互：

- 类型标签显示数量：`前端源码 8`、`样式 2`。
- 支持多选。
- 点击类型只过滤可见列表，不自动勾选。
- `选择当前类型` 按钮可批量勾选当前筛选结果。
- `排除当前类型` 可取消勾选当前类型。

### 10.8 后缀筛选

后缀筛选以标签云呈现：

```text
.vue 5   .ts 3   .scss 2   .json 1   .png 4
```

规则：

- 只显示当前操作范围内存在的后缀。
- 标签数量按候选文件计算。
- 支持搜索后缀。
- 支持 `全选后缀`、`清空后缀`。
- 点击 `.png` 后，只显示图片文件。
- 点击 `选择当前筛选结果` 后，才改变勾选状态。

### 10.9 路径筛选

路径筛选用于大目录提交。

控件：

- 目录树。
- 路径输入框。
- 常用目录快捷标签。

规则：

- 路径筛选不能突破入口范围。
- 右键 `src/pages/order` 打开时，目录树根就是 `src/pages/order`。
- 用户输入 `../user` 不生效，提示 `不能超出当前提交范围`。

### 10.10 搜索框

支持普通搜索和简单语法。

普通搜索：

- 匹配文件名。
- 匹配相对路径。
- 匹配后缀。

高级语法：

```text
ext:vue
type:config
status:modified
path:src/pages/order
size:>1MB
lock:mine
changelist:task-123
```

搜索结果只影响可见列表，不自动勾选。

### 10.11 模板预设与文件筛选

模板选择器放在提交信息上方和顶部工具栏都可进入。

模板由三部分组成：

```json
{
  "name": "前端页面",
  "messageTemplate": "需求: 完成 ${ticket} ${summary}",
  "fileRules": {
    "include": ["src/**/*.vue", "src/**/*.ts", "src/**/*.tsx", "src/**/*.scss"],
    "exclude": ["dist/**", "node_modules/**", "*.log"]
  },
  "checks": {
    "warnLargeFiles": true,
    "requireTicket": false
  }
}
```

### 10.12 默认模板预设

| 模板 | 默认文件筛选 | 默认提交信息 |
| --- | --- | --- |
| 需求开发 | 排除生成物和日志，包含源码、样式、配置 | `需求: ${summary}` |
| 缺陷修复 | 包含源码、配置、测试文件 | `缺陷: 修复 ${summary}` |
| 前端页面 | `src/**/*.vue`、`src/**/*.ts`、样式、图片 | `需求: 完成页面 ${summary}` |
| 后端接口 | 后端源码、配置、SQL | `需求: 完成接口 ${summary}` |
| 配置调整 | 配置文件、脚本、环境样例 | `配置: 调整 ${summary}` |
| 文档更新 | Markdown、Office、PDF | `文档: 更新 ${summary}` |
| 样式资源 | 样式、图片、字体 | `优化: 调整样式资源 ${summary}` |
| 数据库脚本 | SQL、迁移脚本 | `数据库: 更新脚本 ${summary}` |
| 发布打包 | 配置、脚本、版本文件 | `发布: ${version} ${summary}` |

### 10.13 模板筛选交互规则

用户选择模板后：

1. 提交信息区域填入模板。
2. 页面计算当前范围内匹配模板的文件数量。
3. 显示提示：

```text
“前端页面”模板匹配当前范围内 7 个文件，另有 3 个文件不匹配。
```

用户可选：

- `勾选匹配文件`：只勾选模板匹配文件，保留用户锁定勾选项。
- `仅显示匹配文件`：不改变勾选，只过滤列表。
- `标记为建议`：给匹配文件加推荐标记。
- `只使用提交信息`：不应用文件筛选。

### 10.14 用户手动勾选保护

如果用户已经手动勾选文件，再切换模板：

- 不直接清空已有选择。
- 提示：`检测到你已手动选择 5 个文件，是否用模板筛选覆盖？`
- 默认按钮：`保留手动选择`。

文件可被用户设置为 `固定选择`：

- 固定选择的文件不受模板批量取消影响。
- 文件行显示小锁图标。

### 10.15 批量勾选规则

按钮定义：

| 按钮 | 行为 |
| --- | --- |
| 全选可提交 | 勾选当前范围内可提交且未被安全排除的文件 |
| 全选当前筛选结果 | 勾选当前可见列表 |
| 清空选择 | 取消所有非固定选择 |
| 反选当前筛选结果 | 反选当前可见列表 |
| 只选源码 | 勾选文本源码类型 |
| 排除二进制 | 取消图片、Office、压缩包、未知二进制 |
| 排除未版本控制 | 取消所有 `?` 文件 |

不可提交文件：

- 冲突文件。
- 被其他工作副本锁定且不能提交的文件。
- externals 默认不可提交，除非用户显式允许。

### 10.16 缺失文件处理

缺失文件指 SVN 中存在、本地被直接删除的文件，状态为 `!`。

展示：

- 状态显示 `缺失 !`。
- 行操作：
  - `提交删除`
  - `恢复文件`
  - `查看历史`

提交规则：

- 若用户勾选缺失文件，提交前自动执行或提示执行 `svn remove`。
- 页面展示确认：`这些文件将作为删除提交`。
- 如果用户点击 `恢复文件`，执行 `svn revert` 并刷新。

### 10.17 未版本控制文件处理

状态为 `?`。

默认：

- 显示。
- 不自动勾选。
- 文件行提供 `加入版本控制`。

批量：

- `添加全部当前筛选结果`
- `忽略当前后缀`
- `加入 svn:ignore`
- `从列表隐藏`

提交规则：

- 勾选 `?` 文件时，提交前先执行 `svn add`。
- 对大文件、敏感文件二次确认。

### 10.18 二进制文件处理

二进制文件包括图片、Office、压缩包、字体等。

展示：

- 不显示文本 diff。
- 显示文件大小、修改时间、缩略图或文件图标。
- 如果支持图片预览，显示旧版和新版缩略图。

提交前检查：

- 大于阈值提示。
- 如果文件有 `svn:needs-lock` 但未锁定，提示先锁定。
- 如果是 Office 文件，提示无法展示文本差异。

### 10.19 锁定文件处理

文件行锁状态：

- 未锁。
- 我锁定。
- 他人锁定。
- 需要锁但未锁。

操作：

- 锁定。
- 解锁。
- 查看锁信息。
- 强制解锁，需二次确认。

提交规则：

- 我锁定的文件可提交。
- 他人锁定文件阻止提交。
- 提交后默认释放锁，提供 `提交后保留锁` 复选框。

### 10.20 冲突文件处理

冲突文件在提交页：

- 显示在顶部红色区域。
- 默认不可勾选。
- 提供 `去解决冲突`。
- 解决后返回提交页，自动刷新。

如果提交范围外有冲突：

- 显示黄色提醒：`工作区其他位置有冲突，不影响当前范围提交`。
- 不阻止当前提交。

### 10.21 差异预览

用户点击文件后右侧显示差异。

模式：

- 与 BASE 比较。
- 与 HEAD 比较。
- 与指定修订号比较。

功能：

- 上一个变更块。
- 下一个变更块。
- 复制 diff。
- 打开完整 diff。
- 对单个文件还原。
- 对单个变更块还原，后续阶段实现。

空状态：

- 未选择文件：显示 `选择左侧文件查看差异`。
- 二进制文件：显示文件信息和历史入口。
- 新增文件：显示新增内容。
- 删除文件：显示删除前内容。

### 10.22 提交信息区

字段：

- 提交摘要，单行。
- 详细说明，多行。
- 工单号。
- 类型。
- 影响范围。
- 提交后保留锁。

快捷：

- 最近提交信息。
- 最近前缀。
- 模板。
- AI 生成。
- 清空。
- 复制。

### 10.23 提交信息模板变量

支持变量：

```text
${type}
${ticket}
${summary}
${scope}
${filesCount}
${user}
${date}
${branch}
```

模板示例：

```text
${type}: ${summary}

关联: ${ticket}

```

### 10.24 AI 生成提交信息

按钮：

- `AI 生成摘要`
- `AI 生成详细说明`
- `AI 检查提交风险`

规则：

- 默认只发送已勾选文件的 diff。
- 用户可选择只发送文件名和状态。
- 生成前显示将发送的文件数量和字符数。
- 生成结果不自动提交，必须用户确认。
- AI 不允许自动勾选文件。

### 10.25 提交前检查

点击提交后执行：

1. 检查是否有勾选文件。
2. 检查提交信息是否为空。
3. 检查范围内是否有冲突文件被勾选。
4. 检查远端是否有更新。
5. 检查缺失文件是否确认提交删除。
6. 检查未版本控制文件是否需要 `svn add`。
7. 检查敏感文件。
8. 检查大文件。
9. 检查锁状态。
10. 检查 externals。

检查结果分级：

- 阻止：冲突、空信息、他人锁定、svn add 失败。
- 警告：远端有更新、大文件、敏感文件、二进制文件。
- 提醒：提交信息过短、未填写工单号。

### 10.26 远端更新检查

默认点击提交时检查远端：

- 若远端无更新，继续提交。
- 若远端有更新，提示：
  - `先更新并继续`
  - `查看远端变更`
  - `仍然提交`
  - `取消`

团队可配置为必须先更新：

```json
"svnWorkbench.commit.requireUpdateFirst": true
```

### 10.27 提交流程

标准流程：

1. 用户选择文件。
2. 用户填写提交信息。
3. 点击 `提交`。
4. 执行提交前检查。
5. 对 `?` 文件执行 `svn add`。
6. 对 `!` 文件执行 `svn remove`。
7. 执行 `svn commit selectedPaths -m message`。
8. 显示进度和输出。
9. 成功后显示新修订号。
10. 刷新状态。

成功提示：

```text
提交成功：r12876
已提交 8 个文件
```

按钮：

- `复制提交摘要`
- `查看日志`
- `关闭`

### 10.28 提交失败处理

失败时展示：

- 用户可读错误。
- 原始 SVN 错误摘要。
- 可能原因。
- 推荐操作。

示例：

| 错误 | 推荐 |
| --- | --- |
| 认证失败 | 换账号或打开认证管理 |
| Out of date | 先更新再提交 |
| 冲突 | 进入冲突中心 |
| 文件被锁 | 查看锁信息 |
| 路径不存在 | 刷新状态或恢复文件 |

### 10.29 提交页验收用例

| 用例 | 预期 |
| --- | --- |
| 右键 `src/a` 提交 | 只显示 `src/a` 内文件 |
| 右键文件提交 | 只显示该文件 |
| 选择 `.vue` 后缀 | 只过滤可见列表，不自动勾选 |
| 点击全选当前筛选 | 只勾选当前可见 `.vue` 文件 |
| 选择前端模板 | 提示匹配数量，不直接覆盖手动选择 |
| 当前范围有 missing | 显示提交删除和恢复 |
| 当前范围外有冲突 | 提醒但不阻止当前范围提交 |
| 勾选敏感文件 | 提交前二次确认 |
| 勾选未版本控制文件 | 提交前执行 `svn add` |
| 他人锁定文件 | 阻止提交 |

## 26. 细节验收清单

### 26.1 右键文件夹提交

- 右键 `src/a` 时不显示 `src/b` 文件。
- `全选` 不会选中范围外文件。
- 模板筛选不引入范围外文件。
- 搜索清空后仍只显示范围内文件。
- 提交成功后不改变其他文件夹文件状态。

### 26.2 文件类型筛选

- `.vue`、`.ts`、`.scss` 能被正确归类为前端相关。
- `.png`、`.jpg` 能被归类为图片。
- 无后缀文件归类为其他。
- 二进制文件不打开文本 diff。
- 类型标签数量与当前范围一致。

### 26.3 模板筛选

- 选择模板后只提示，不自动覆盖手动选择。
- 用户选择 `勾选匹配文件` 后，只勾选当前范围内匹配文件。
- 固定选择文件不会被模板取消。
- 模板规则 include/exclude 同时生效。
- 模板可配置为只填提交信息。

### 26.4 提交安全

- 冲突文件阻止提交。
- 空提交信息阻止提交。
- 他人锁定文件阻止提交。
- 敏感文件二次确认。
- 大文件二次确认。
- missing 文件提交前确认删除。
- 未版本控制文件提交前执行 add。
