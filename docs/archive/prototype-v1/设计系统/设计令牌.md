# SVN Workbench · 整合设计令牌（原型构建师直接消费版）

> **用途**：SVN Workbench（VS Code 扩展内嵌 webview）全部面板**统一消费**的令牌与组件规范。下游原型构建师把本文档第 2 节的 `:root` 片段原样粘贴到 webview 根样式，即可获得全部令牌。
>
> **运行环境**：VS Code 内嵌 webview（Chromium 内核，支持 `color-mix()`、`var()` 嵌套回退）。
>
> **最高约束（不可妥协）**：①所有颜色、焦点、阴影、边框令牌**全部引用 `var(--vscode-*)` 主题变量，严禁任何硬编码 hex**；②深色默认且自动支持浅色；③状态色统一用 VS Code 语义色，**不引入任何第三方品牌色**；④本文档**不新增任何令牌、不新增任何颜色**，全部值来自 v1 主令牌与 addendum 扩展令牌。
>
> **来源**：`v1-design-tokens.md`（§1–§8 主令牌）+ `design-tokens-addendum-undesigned.md`（§9 未设计 5 页扩展）。本文件为二者收敛整合，无新定义。

## 1. 设计系统选型结论

**基底 = VS Code 设计语言本身**（即 `var(--vscode-*)` 体系）。这是不可妥协的品牌上下文——SVN Workbench 不是独立站点，而是寄生于 VS Code 宿主的 webview 面板，其主题色由宿主注入，**所有色彩必须以宿主变量为唯一真相源**，否则会在用户切换深浅主题 / 自定义主题时崩坏。

我们从内置设计系统中挑选**组件模式借鉴基底**——只借其「节奏与秩序」（间距密度、层级表达、状态色克制用法），**不借任何品牌色**：

| 借鉴对象 | 角色 | 借什么（仅模式） | 不借什么 |
|---------|------|----------------|---------|
| **Linear** | 主基底 | 深色优先、发丝级边框（hairline）、克制留白、高密度列表、状态色极省、键盘驱动层级 | Linear 紫等任何品牌色 |
| **Vercel** | 辅 | 单色高对比、零装饰、几何锐利；动作条 / 批量操作条「高对比、无废话」 | Vercel 黑等任何品牌色 |
| **Raycast** | 辅 | macOS 原生紧凑密度、圆角但克制、分组缩进、状态点清晰；卡片「左条 + 内容」骨架 | Raycast 蓝等任何品牌色 |

**为何不可妥协**：品牌上下文 = VS Code 主题。webview 必须「像 VS Code 原生的一部分」，而非一个套着第三方皮肤的外来面板。任何第三方品牌色（紫 / 蓝 / 黑点缀）都会破坏宿主一致性，在浅色主题或高对比主题下尤其刺眼。因此：

- 所有色彩令牌一律走 `var(--vscode-*)`；
- 第三方品牌色在本项目**零出现**；
- 借鉴仅停留在「间距 / 层级 / 状态色克制用法」的方法论层面。

## 2. 完整 `:root` 令牌块（可直接复制）

> 把下面的片段**原样**粘贴到 webview 根样式（`<style>` 顶层或全局 CSS 入口）即可。
>
> **离线预览兜底说明**：以下所有 `var(--vscode-*)` 均依赖 VS Code 宿主注入的主题变量。当 webview 在宿主之外离线预览（未注入宿主变量）时这些变量为空，需另行注入**兜底默认值**；该默认值**仅在 webview 未注入宿主变量时兜底生效**，且同样须为 `var(--vscode-*)` 或 vscode 语义色，**不得写 hex**。语义色变量（如 `warningForeground`）已内置 `var()` 嵌套回退，旧主题也能显示合理语义色。

```css
:root {
  /* —— 前景 / 背景层级 —— */
  --color-fg: var(--vscode-foreground);
  --color-fg-secondary: var(--vscode-descriptionForeground);
  --color-fg-disabled: var(--vscode-disabledForeground);
  --color-fg-link: var(--vscode-textLink-foreground);
  --color-icon: var(--vscode-icon-foreground);
  --color-bg-canvas: var(--vscode-panel-background);
  --color-bg-surface: var(--vscode-sideBar-background);
  --color-bg-editor: var(--vscode-editor-background);
  --color-bg-list: var(--vscode-list-background);
  --color-bg-input: var(--vscode-input-background);
  --color-bg-dropdown: var(--vscode-dropdown-background);
  --color-bg-section-header: var(--vscode-sideBarSectionHeader-background);
  --color-bg-hover: var(--vscode-list-hoverBackground);
  --color-bg-selected: var(--vscode-list-activeSelectionBackground);
  --color-bg-selected-inactive: var(--vscode-list-inactiveSelectionBackground);
  --color-fg-selected: var(--vscode-list-activeSelectionForeground);
  --color-bg-widget: var(--vscode-editorWidget-background);
  --color-border: var(--vscode-panel-border);
  --color-border-widget: var(--vscode-widget-border);
  --color-border-strong: var(--vscode-contrastBorder, var(--vscode-panel-border));

  /* —— 语义状态色（fg + bg 变体） —— */
  --color-error-fg: var(--vscode-errorForeground);
  --color-error-bg: color-mix(in srgb, var(--vscode-errorForeground) 14%, var(--vscode-panel-background));
  --color-warning-fg: var(--vscode-warningForeground, var(--vscode-charts-yellow));
  --color-warning-bg: color-mix(in srgb, var(--vscode-warningForeground, var(--vscode-charts-yellow)) 14%, var(--vscode-panel-background));
  --color-info-fg: var(--vscode-textLink-foreground);
  --color-info-bg: color-mix(in srgb, var(--vscode-textLink-foreground) 14%, var(--vscode-panel-background));
  --color-success-fg: var(--vscode-charts-green);
  --color-success-bg: color-mix(in srgb, var(--vscode-charts-green) 14%, var(--vscode-panel-background));

  /* —— 差异色（增/删/改） —— */
  --color-diff-add-fg: var(--vscode-charts-green);
  --color-diff-add-bg: var(--vscode-diffEditor-insertedTextBackground, var(--vscode-charts-green));
  --color-diff-add-gutter: var(--vscode-editorGutter-addedBackground, var(--vscode-charts-green));
  --color-diff-del-fg: var(--vscode-charts-red, var(--vscode-errorForeground));
  --color-diff-del-bg: var(--vscode-diffEditor-removedTextBackground, var(--vscode-charts-red));
  --color-diff-del-gutter: var(--vscode-editorGutter-deletedBackground, var(--vscode-charts-red));
  --color-diff-mod-fg: var(--vscode-charts-yellow, var(--vscode-charts-orange));
  --color-diff-mod-gutter: var(--vscode-editorGutter-modifiedBackground, var(--vscode-charts-yellow));

  /* —— 焦点 / 阴影 / 按钮 / 徽标 / 进度 —— */
  --color-focus: var(--vscode-focusBorder);
  --shadow-widget: var(--vscode-widget-shadow);
  --color-btn-primary-bg: var(--vscode-button-background);
  --color-btn-primary-fg: var(--vscode-button-foreground);
  --color-btn-primary-hover: var(--vscode-button-hoverBackground);
  --color-btn-secondary-bg: var(--vscode-button-secondaryBackground);
  --color-btn-secondary-fg: var(--vscode-button-secondaryForeground);
  --color-btn-secondary-hover: var(--vscode-button-secondaryHoverBackground);
  --color-badge-bg: var(--vscode-badge-background);
  --color-badge-fg: var(--vscode-badge-foreground);
  --color-progress: var(--vscode-progressBar-background);
}
```

## 3. 字体令牌

> VS Code **未暴露字体大小 / 字重变量**，故字号阶梯按 VS Code 原生 UI 节奏（11 / 12 / 13 / 15 / 18）定义（px 为几何值，非颜色，不违反「禁硬编码 hex」）。**字体族首值必须是 `var(--vscode-*)` 变量**。

| Token | 值 | 用途 |
|-------|----|----|
| `--font-family` | `var(--vscode-font-family)` | 全局 UI 字体（继承宿主） |
| `--font-family-mono` | `var(--vscode-editor-font-family, 'SFMono-Regular', Consolas, 'Liberation Mono', Menlo, monospace)` | 路径、diff、提交信息、命令名（等宽，首值为编辑器字体变量） |
| `--font-size-xs` | `11px` | 徽标、微型标签、计数 |
| `--font-size-sm` | `12px` | 次级说明、列表元数据 |
| `--font-size-md` | `13px` | 正文 / 列表主文本（webview 基准） |
| `--font-size-lg` | `15px` | 区块标题、分组头 |
| `--font-size-xl` | `18px` | 面板顶部标题（仓库条 / 范围条大标题） |
| `--font-weight-regular` | `400` | 常规 |
| `--font-weight-medium` | `500` | 强调文本、按钮标签 |
| `--font-weight-semibold` | `600` | 区块标题 |
| `--font-weight-bold` | `700` | 面板标题、强提示 |
| `--line-height-tight` | `1.3` | 标题 |
| `--line-height-base` | `1.5` | 正文 / 列表行 |
| `--line-height-relaxed` | `1.6` | 多行提交信息、说明段落 |

## 4. 间距 / 尺寸令牌（4px 基准）

> VS Code **未暴露间距 / 圆角变量**，故按 VS Code 原生 4px 密度节奏定义（px 为几何值，非颜色）。密度为「紧凑专业」（借鉴 Linear / Raycast），非营销型宽松。

| Token | 值 | 用途 |
|-------|----|----|
| `--space-1` | `4px` | 行内最小间距、icon 与文本间隙 |
| `--space-2` | `8px` | 紧凑项间距、控件内边距（纵向） |
| `--space-3` | `12px` | 控件内边距（横向）、相关项间距 |
| `--space-4` | `16px` | 面板外边距、区块内边距 |
| `--space-5` | `20px` | 主区块之间间距 |
| `--space-6` | `24px` | 大区块分隔 |
| `--space-7` | `32px` | 面板内最大留白 |
| `--space-8` | `40px` | 跨区大间距（极少用） |

**尺寸 / 圆角 / 描边**

| Token | 值 | 用途 |
|-------|----|----|
| `--control-height` | `26px` | 按钮 / 输入 / 下拉标准高度（对齐 VS Code 控件） |
| `--control-height-sm` | `22px` | 紧凑控件（图标按钮、微型输入） |
| `--control-height-lg` | `30px` | 主行动按钮（提交 / 应用） |
| `--row-height` | `26px` | 列表 / 树行高（紧凑但带 checkbox 可读） |
| `--row-height-header` | `22px` | 分组头 / 区块标题条高度 |
| `--radius-sm` | `2px` | 输入 / 按钮 / 下拉圆角（VS Code 近锐利） |
| `--radius-md` | `3px` | 卡片 / 状态卡圆角 |
| `--radius-badge` | `3px` | 徽标圆角（矩形小圆角，非 pill） |
| `--radius-lg` | `4px` | 浮层 / 结果预览容器圆角 |
| `--border-width` | `1px` | 所有 hairline 描边宽度 |
| `--indent-step` | `16px` | 树每级缩进（配合 `--vscode-tree-indentGuidesStroke`） |

## 5. 组件规范速查（原型构建师直接指引）

> 通用：所有组件 hover / 选中 / 焦点态一律引用第 1–4 节令牌；**禁止**自绘 hex 色块或渐变。状态色只用于**徽标文字 / 左条 / 关键计数 / 图标**，绝不整块铺色（见 §6 红线⑦）。

### 5.1 按钮

| 类型 | 规范 |
|------|------|
| **Primary** | 底 `--color-btn-primary-bg`，前景 `--color-btn-primary-fg`，高 `--control-height-lg`，圆角 `--radius-sm`，内边距 `0 --space-3`；hover 底 `--color-btn-primary-hover`；用于「提交 / 应用 / 更新当前范围」等主行动 |
| **Secondary** | 底 `--color-btn-secondary-bg`，前景 `--color-btn-secondary-fg`，高 `--control-height`，圆角 `--radius-sm`；hover 底 `--color-btn-secondary-hover`；用于「取消 / 刷新 / 打开差异对比」 |
| **Icon 按钮** | 方 `--control-height-sm` × `--control-height-sm`，圆角 `--radius-sm`，透明底；hover 底 `--color-bg-hover`；icon 用 codicon，色 `--color-icon`；用于「刷新 / 折叠 / 全选」等工具栏动作 |
| **Disabled** | 前景 `--color-fg-disabled`，底沿用 secondary 但降透明度；不可点击；**不**用红色禁用 |
| **Focus ring** | `outline: 1px solid var(--color-focus); outline-offset: -1px;` 或 `box-shadow: 0 0 0 1px var(--color-focus);`（统一用 `--vscode-focusBorder`，深浅自动） |

### 5.2 输入 / 文本域 / 下拉

| 组件 | 规范 |
|------|------|
| **Input** | 高 `--control-height`，底 `--color-bg-input`，前景 `--color-fg`，边框 `1px solid var(--color-border)`，圆角 `--radius-sm`，内边距 `0 --space-2`；placeholder 用 `var(--vscode-input-placeholderForeground)`；focus 边框 `var(--color-focus)` |
| **Textarea（提交信息框）** | 底 `--color-bg-input`，字体 `--font-family-mono`，字号 `--font-size-md`，行高 `--line-height-relaxed`，圆角 `--radius-sm`；最小高 96px（约 4 行）；支持模板 / 预设注入 |
| **Dropdown（筛选 / 分组 / 预设）** | 触发器高 `--control-height`，底 `--color-bg-dropdown`，圆角 `--radius-sm`；展开列表底 `--color-bg-dropdown`，项高 `--row-height`，hover 底 `--color-bg-hover`，选中底 `--color-bg-selected`；展开容器阴影 `--shadow-widget`，边框 `1px solid var(--color-border-widget)` |

### 5.3 列表 / 树（文件列表、冲突文件列表、验收清单、队列列表、差异文件列表）

| 项目 | 规范 |
|------|------|
| **行高** | `--row-height`（26px）；分组头 `--row-height-header`（22px），底 `--color-bg-section-header`，字 `--font-size-sm` 中粗 |
| **Hover** | 底 `--color-bg-hover` |
| **选中（键盘 / 单选）** | 底 `--color-bg-selected`，前景 `--color-fg-selected`；失焦选中底 `--color-bg-selected-inactive` |
| **Checkbox** | 用 VS Code 原生复选观感：底 `--vscode-checkbox-background`、勾选标记 `--vscode-checkbox-foreground`、边框 `--vscode-checkbox-border`；行内左侧 20px 槽位 |
| **缩进分组** | 每级 `--indent-step`（16px）；缩进参考线 `var(--vscode-tree-indentGuidesStroke)`（发丝级，借鉴 Raycast 分组） |
| **折叠** | 分组头前 `chevron-right`（收）/ `chevron-down`（展）codicon，色 `--color-fg-secondary` |
| **状态标记** | 行尾用 codicon + 语义色（冲突 = `icon-warning` / `--color-warning-fg`；已解决 = `icon-check` / `--color-success-fg`；新增 = `--color-diff-add-fg` 等） |

### 5.4 徽标 Badge（状态计数）

| 项 | 规范 |
|----|------|
| 外观 | 底 `--color-badge-bg`，前景 `--color-badge-fg`，圆角 `--radius-badge`，内边距 `0 --space-1`，字号 `--font-size-xs`，字重 medium；**矩形小圆角（非 pill，符合 VS Code 原生）** |
| 语义计数 | 变更 / 新增 / 删除 / 冲突计数徽标；冲突可用 `--color-warning-fg` 文字、错误可用 `--color-error-fg` 文字（**背景仍走 badge 底，避免彩虹堆色**） |
| 密度 | 状态摘要条内徽标间距 `--space-2`；借鉴 Raycast 紧凑间距 |

### 5.5 分隔条 / 状态摘要条 / 批量操作条

| 组件 | 规范 |
|------|------|
| **分隔条（Divider）** | `1px solid var(--color-border)`，上下留白 `--space-4`；Vercel 风：用实线而非大留白 |
| **状态摘要条** | 顶部固定条，底 `--color-bg-surface`，下边框 `1px solid var(--color-border)`；内含「变更 / 新增 / 删除 / 冲突」徽标组 + 范围路径（mono 字体）；高约 `calc(--row-height-header + --space-2)` |
| **批量操作条** | 次工具栏：全选 / 全不选 / 反选 / 展开折叠；底 `--color-bg-widget` 或 `--color-bg-surface`，上下 1px `--color-border`（Vercel 零装饰）；图标按钮 + 文本标签混排，间距 `--space-2`；focus / hover 同 5.1 |

### 5.6 卡片（环境体检状态卡 / 状态卡 / 横幅）

| 项 | 规范 |
|----|------|
| 骨架 | 借鉴 Raycast：左侧 **4px 状态色竖条** + 右侧内容区；卡底 `--color-bg-surface`，边框 `1px solid var(--color-border)`，圆角 `--radius-md`，内边距 `--space-3` |
| ok 卡 | 左条 `--color-success-fg`，标题 `icon-check` + 「已就绪」，内容引导文案 `--color-fg-secondary` |
| warning 卡 | 左条 `--color-warning-fg`，标题 `icon-warning` + 「需配置」，含「去安装 / 去配置」次按钮 |
| error 卡 | 左条 `--color-error-fg`，标题 `icon-error` + 「缺失 / 失败」，含明确引导动作；**不恐吓、不静默退出** |
| AI 未配置 | 降级「手动模式」提示，用 info 卡（`--color-info-fg` + `icon-info`），不抛错阻断 |
| svn 缺失 | 渲染 warning / error 引导卡（指向 `svnWorkbench.svn.path`），**不静默退出** |
| 密度 | 卡片间距 `--space-4`，组内卡间距 `--space-3` |

### 5.8 左右 Split 对比视图（冲突中心：ours / theirs / working + 结果）

| 项 | 规范 |
|----|------|

## 6. 硬性自检红线（验收门控）

原型交付前必须逐条 grep / 核对，任一不达标即不予验收：

1. **零 hex**：组件样式中不得出现 `#` 开头的 hex（除 `transparent`）。所有 color / background / border-color 必须引用 `var(--vscode-*)` 派生令牌。
2. **无裸几何值**：间距只走 `--space-1..8`、圆角只走 `--radius-*`、高度只走 `--control-height*` / `--row-height*`、字号只走 `--font-size-*`、行高只走 `--line-height-*`；不得出现裸 `32px` / `6px` / `18px` / `1.45` 之类（如源文件 `height: 32px`、`border-radius: 4px/6px`、`.status/.result/.panel` 用 6px、`main padding: 18px`、`font: 13px/1.45` 一律改令牌）。
3. **无 `innerHTML` 拼接**：所有渲染改 Svelte 受控渲染（与既有 6 功能原型一致）；组件代码中不得出现 `innerHTML` 拼接（源文件 `providerPreset.innerHTML` / `renderScenarioModels` / `showModelList` / `renderPreview` 必须消除）。
4. **成功色统一**：全站成功语义一律用 `--color-success-fg`（= `--vscode-charts-green`）；不得用 `--vscode-testing-iconPassed` 或其它成功色（源文件页面 2 的 `--ok` 误用须修正）。
5. **两处降级分支必须存在**：①「AI 未配置 → 手动模式 info 卡」（`icon-info` + 左条 `--color-info-fg`，不抛错、不阻断）；②「svn 缺失 → 引导卡」（`icon-warning`/`icon-error` 左条，指向 `svnWorkbench.svn.path`，不静默退出）。
6. **禁浅色硬编码**：不得写任何 `@media (prefers-color-scheme: light)` 或按主题的 hex 覆盖 / 条件分支；信任 `var(--vscode-*)` 自动适配深浅主题。
7. **状态色克制（Anti-Slop）**：状态色只用于**徽标文字 / 左条 / 关键计数 / 图标**，绝不整行 / 整块铺语义色；零渐变、零重阴影（仅浮层用 `--shadow-widget`）；圆角上限 `--radius-lg`（4px），徽标矩形小圆角（非 pill）；不引入任何第三方品牌色；全局单一 `--font-family`（仅路径 / diff / 代码用 `--font-family-mono`）。

> **深浅自动保证**：本文件全部色彩令牌均为 `var(--vscode-*)`（或基于它们的 `color-mix` / `var` 嵌套），同一份规范在深色 / 浅色 VS Code 主题下**自动切换**，无需为浅色写第二套定义。验证方法：深浅主题下各开一次 webview，核对列表 hover、选中、状态卡左条、diff 增删底色在两种主题下均清晰可读（对比度 ≥ WCAG AA）。
