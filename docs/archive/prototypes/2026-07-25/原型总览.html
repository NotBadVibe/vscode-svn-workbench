使用与交付说明

① 预览方式

浏览器双击本文件或任意 高保真原型/*.html 即可预览；也可在 VS Code 中由对应命令（如 SVN：提交当前范围）打开为 webview 宿主面板。原型深色优先，在 VS Code 浅色主题下随宿主变量自动切换为浅色。

② 设计系统归属

本套原型一律采用 VS Code 设计语言（基底 = var(--vscode-*) 主题变量），组件颜色全部引用派生令牌，不写硬编码 hex、不引入任何第三方品牌色；图标以单色 inline SVG 占位（标注 codicon 名），字体继承 var(--vscode-font-family)。

③ 降级演示

每个原型页面顶部均含 DemoBar（演示开关），可切换「AI 未配置 / svn 缺失 / 加载中 / 空态」等状态，仅用于原型演示；真实状态由 VS Code 宿主读取注入，不与实现绑定。

④ 动作占位

原型中所有按钮 / 下拉 / 列表项均为命令占位（如 svnWorkbench.commitFolder、svnWorkbench.openConflictCenter），不绑定真实后端实现；后续 Svelte 重写时按命令契约接入。
