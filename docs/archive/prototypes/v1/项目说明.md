## 三、设计系统要点

- **基底 = VS Code 设计语言**：所有颜色一律引用 `var(--vscode-*)` 主题变量，由宿主注入；深色优先并随主题自动切换为浅色（深浅同源，无第二套定义）。
- **零硬编码 hex（组件样式）**：组件样式段全部引用派生令牌（如 `--color-fg` / `--color-bg-surface`），仅离线预览兜底 `:root` 块含 hex 默认值（供浏览器独立预览，真实 webview 中由宿主覆盖）。
- **字体继承宿主**：`font-family` 首值 `var(--vscode-font-family)`，路径/diff/提交信息用 `var(--font-family-mono)`；字号阶梯按 VS Code 原生节奏（11/12/13/15/18）。
- **图标 = codicon 占位**：统一以单色 inline SVG（`<symbol>` + `<use>`，`currentColor`）占位，旁注 codicon 名，不引入第三方图标库。
- **令牌化几何值**：间距走 `--space-1..8`、圆角 `--radius-*`、控件高度 `--control-height*`、字号 `--font-size-*`，对齐 VS Code 原生 4px 密度。
- **受控渲染**：交互均用原生内联 `<script>` 操作 `textContent` / `classList` / `createElement` / `setAttribute`，禁用 `innerHTML` 字符串拼接。
- **克制 Anti-Slop**：状态色只用于徽标文字 / 左条 / 关键计数 / 图标，零渐变、零重阴影、圆角 ≤ 4px，不引入任何第三方品牌色。
- **全局降级一致**：AI 未配置 → 手动模式 info 卡（不抛错）；svn 缺失 → 引导卡（指向 `svnWorkbench.svn.path`，不静默退出）。
