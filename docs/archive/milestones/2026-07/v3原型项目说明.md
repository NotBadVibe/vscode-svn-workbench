# SVN Workbench v3 · VS Code 右键模块原型

> 状态：ARCHIVED，原 v3 原型说明。当前文档体系见 [`README.md`](./README.md)。

## 设计定位

这版不再把 SVN Workbench 设计成必须先进入首页的完整工作台，而是将它作为一组依附于 VS Code 的模块化能力：用户在 Explorer、编辑器标签或 Svelte 文件树上右键，直接选择当前需要的功能。所有可见业务界面统一使用 Svelte 5，同一 Workbench Shell 根据命令进入不同聚焦模块。

VS Code 的 Explorer 右键和命令面板只负责提供入口；SVN 状态、文件选择、Diff、历史、提交、冲突、设置、进度和 AI 交互统一由 Svelte 模块承载。完整技术决策、迁移和验收规则见 [`Svelte统一UI开发改造与验收方案.md`](./Svelte统一UI开发改造与验收方案.md)。

## 交付物

- `原型总览.html`：日常使用主原型。模拟 Explorer 右键、VS Code 原生动作和 8 个聚焦任务模块。
- `功能全景与状态矩阵.html`：设计评审原型。覆盖状态管理、Changelist、多仓库、AI 任务代理、异常恢复和高级仓库能力。
- `完整功能清单与验收矩阵.md`：功能完整性的权威清单，以 ID 跟踪入口、表面、优先级和原型证据。
- `设计分析与开发映射.md`：从现有代码迁移到新架构的产品与工程建议。
- `Svelte统一UI开发改造与验收方案.md`：统一 Svelte UI 的实施架构、阶段计划、质量门槛和发布验收依据。
- `中文用户体验与页面滚动优化及验收方案.md`：中文术语、任务化页面、局部滚动和真实视口测试的增量实施规范。

两个 HTML 原型仍属于静态交互演示，不证明最终技术实现；其中遗留的原生表面模拟只用于追溯功能流程，正式开发和 UI 验收以 Svelte 改造方案为准。

## 如何体验

1. 打开 `原型总览.html` 后，右键左侧 Explorer 中的 `src/order` 文件夹；初次进入时菜单默认展开，方便直接看到结构。
2. 在 `SVN Workbench` 子菜单中选择智能提交、更新、查看修改或历史。
3. 将鼠标移到或点击 `AI 助手`、`冲突与恢复`、`更多 SVN 操作`，查看二级模块。
4. 点击命令后，编辑区只打开完成该任务所需的 Svelte 聚焦模块，不先进入首页。
5. 查看差异、冲突合并、通知、确认和设置等行为使用统一的 Svelte 组件与状态表达。
6. 选择“AI 任务代理”或高级仓库工具会进入 `功能全景与状态矩阵.html` 的对应页；该页面用于评审完整状态，不是日常大工作台。

## 右键菜单分层

### 第一层：最常用

- 智能提交此范围
- 更新此范围
- 查看本地修改
- 查看历史

### AI 助手

- 审查此范围
- 智能拆分提交
- 生成提交说明
- 分析影响与测试
- 解释当前文件修改
- AI 任务代理：把自然语言目标拆成可审阅、可逐步批准的 SVN 计划

### 冲突与恢复

- 打开冲突处理
- 在 VS Code 合并编辑器中打开
- 还原本地修改（破坏性操作，正式实现必须二次确认）

### 更多 SVN 操作

- 刷新 SVN 状态
- Add / Delete
- 添加到忽略列表
- 复制 URL / 在仓库中显示
- 锁定 / 解锁所选文件
- SVN 属性
- Cleanup 与中断恢复
- 分支、标签、Switch、Relocate 与 Merge
- 仓库浏览器
- Patch、本地搁置与发布说明
- 环境检查与设置

这些命令不会在任何上下文里全部同时显示。正式实现已由原生 SCM 的 `contextValue` 和 Svelte 文件树按已修改、冲突、未版本化、多选和混合仓库精确裁剪；Explorer 子菜单承担工作区级模块入口，并在 Host 执行前再次校验范围。原型中的“上下文矩阵”给出了完整规则。

## 统一 Svelte 功能表面原则

| 功能 | 推荐表面 |
| --- | --- |
| 查看文件差异 | Svelte Diff 模块，编辑能力按需懒加载 |
| 查看单文件合并 | Svelte 冲突模块与合并视图 |
| 生成提交说明 | Svelte 提交模块预览并写入统一草稿 |
| 更新无风险范围 | Svelte 更新预览、进度和结果 |
| 智能提交 | Svelte 提交模块 |
| AI 变更审查 | Svelte AI 审查模块 |
| 智能拆分 | Svelte Changelist/拆分模块 |
| AI 任务代理 | Svelte 任务代理模块；逐步确认后由 Host 执行 |
| 复杂冲突建议 | Svelte 冲突模块，统一呈现理由、候选和验证步骤 |
| Changelist 与多仓库状态 | Svelte Changes/Changelist 模块 |
| 认证、证书、取消、重试 | Svelte 安全输入、进度和恢复状态；Secret 由 Host 保存 |
| 分支、标签、合并与仓库浏览 | Svelte Repository 模块和小型向导 |
| 查看日志和错误 | Svelte Diagnostics 模块；Host 输出保持脱敏 |
| 环境与团队设置 | Svelte Settings 模块 |

原型不会运行真实 SVN、AI 或文件命令。
