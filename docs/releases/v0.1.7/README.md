## 1. 版本目标

此前版本分别修正功能与结构，本版本以真实任务方式补齐可访问性和细节，不把 axe、`toBeVisible()` 或截图当成真人可用的充分证据。

成功标准：

- 高频区域提供上下文快捷提示和 `?` 帮助，内容来自实际绑定或单一来源。
- 中文 IME composition 期间 Enter/Escape 不触发提交、保存、确认、搜索采用或 AI。
- Dialog、popover、详情、编辑器和列表的焦点进入/返回稳定，无键盘陷阱。
- 每个长内容区有明确滚动归属；sticky 不遮挡末项或当前焦点。
- 720×480、1024×600、1440×900 与 100/125/150/200% 可完成核心任务。
- 状态、差异、选择、风险和焦点不只依赖颜色。
- 负责人完成固定自用任务并记录停顿；有早期用户时追加 3～5 人形成性测试。

### 3.1 V017-A · 三类审计

#### 快捷键清单

记录每个区域真实支持的按键、触发条件、IME 例外、平台差异和冲突。相同快捷键跨模块必须同义；不支持的按键不得出现在帮助中。

#### 焦点图

记录任务打开、Dialog、详情、帮助、AI 面板、查找框、文件切换、后台刷新、保存成功/失败的焦点目标和返回点。

#### 滚动容器图

记录根、页面、Pane、列表、Diff/Editor、Dialog 的纵横向滚动归属、sticky 和 `min-height:0/min-width:0` 链。每个方向最多两层滚动。

### 3.2 V017-B · 上下文快捷帮助

- 列表聚焦后提供紧凑提示：“Space 选择 · Enter 看差异 · Shift+F10 更多 · / 搜索”。
- Diff/Conflicts 提示上一/下一块、保存、查找、undo/redo。
- `?` 打开当前区域帮助，不显示全产品无关命令。
- 帮助从集中 keymap/描述映射生成，防止文档漂移。
- Tooltip 在 hover 和键盘 focus 均出现；图标按钮有明确名称。
- 首次轻提示可关闭，只会话内，不用全屏教程。
- 触摸/鼠标用户不被迫学习键盘。

### 3.3 V017-C · IME 与焦点

覆盖输入：

- 提交说明；
- 搜索与筛选预设名称；
- Diff/冲突编辑器与查找；
- AI 目标/确认事实；
- 属性值、仓库说明、Dialog。

规则：

- compositionstart/end 使用共享、可测试逻辑。
- 候选阶段 Enter 不执行；Esc 先处理输入法/当前浮层。
- 后台快照/进度/结果不抢焦点。
- Dialog 打开进入主操作或安全首项，关闭回触发点；Tab 首尾循环。
- 详情/帮助关闭恢复活动行和滚动位置。
- 项目/文件切换守卫焦点可预测，超时自动检查点后说明结果。

### 3.4 V017-D · 小视口与滚动

目标矩阵：

- 720×480；
- 1024×600；
- 1440×900；
- 100%、125%、150%、200%；
- 分屏及 Terminal/Problems 打开。

修复原则：

- 根 Shell `overflow:hidden`，页面/Pane 明确承担滚动。
- 单栏只有一个主要纵向滚动区；双/三栏各 Pane 独立。
- 代码横向滚动仅在代码区；页面不出现横向滚动。
- 小屏可转单列、步骤或 Tabs；主操作、范围、警告、恢复不被永久裁掉。
- sticky 底栏为末项预留空间，焦点元素可滚入可见区。
- 不使用全局 `overflow:auto !important` 或测试注入 CSS 制造通过。

重点页面：Changes、Commit、Diff、Conflicts、Update、History、Changelists、Repository、Settings、Diagnostics、Activity。

### 3.5 V017-E · 主题与辅助技术语义

- Light/Dark/High Contrast 使用 VS Code tokens。
- 增删行有 `+/-`、文字/aria，不只红绿。
- 选择、焦点、hover、blocked 分别可辨。
- notice、错误、过期、风险用图标+文字+边界。
- reduced motion 下关闭平滑滚动、闪烁和非必要过渡。
- 区域、列表、行、状态、Dialog、Tab、详情语义正确。
- 动态播报节制，不因每次输入重复朗读大段内容。
- 真实读屏在可用设备上按人工清单执行；无设备则保留未完成，不用 axe 代替。

### 3.6 V017-F · 自动化矩阵

- 组件测试：key help、Tooltip、focus return、IME、aria 状态。
- `chinese-scroll.spec.ts`：真实 overflow、scrollTop 变化、末项进入视口。
- `visual-accessibility.spec.ts`：三主题×三尺寸×reduced motion。
- 200%：浏览器缩放或等价真实布局，不只缩小 viewport。
- 列表：5000 项窗口化、PageUp/PageDown/Home/End、Shift+F10。
- Dialog：Tab 循环、Esc、IME、sticky。
- Diff/Conflicts：代码区滚动、当前块、Editor 焦点、查找。
- axe：作为最低机器检查，不作为完成人工读屏的替代。

### 3.7 V017-G · 形成性验收

负责人固定任务：

1. 非 SVN 文件夹恢复；
2. 选择 3 个文件并查看 Diff；
3. 到提交最终确认前；
4. Update 后进入冲突；
5. 编辑/保存并到 Resolve 确认前；
6. 查指定历史；
7. AI 关闭重复核心流程；
8. 5000 文件定位目标。

记录：

- 完成/失败；
- 首次停顿；
- 返回次数；
- 误选动作；
- 完成时间；
- 7 分制范围信心；
- 视口、输入法、主题、设备。

同一文案/控件使负责人反复停顿或早期用户中 2 人停顿 >10 秒，进入本版本修正，不延期为“用户不会用”。
