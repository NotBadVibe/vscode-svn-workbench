## 3. 验收口径

- 首次用户可在三分钟内走完安全闭环演示，且演示止步于最终确认前。
- 所有状态词均可键盘访问到解释，不只依赖悬停；不用颜色单独表达含义。
- History 明确区分"没有匹配"与"尚未加载"；大范围加载可取消。
- 范围栏在危险操作前能快速确认"在哪里、多少项、哪个 revision"，长路径不靠悬停。

## 4. 已知风险

- 引导内容须随模块演进维护，避免与真实页面脱节；引导只复用真实任务窗口的快照，不做平行演示 UI。
- History 作者条件由 Host 对只读 `svn log` 返回集本地过滤；修订号/日期范围先经 Host 校验后才进入 SVN 参数。取消保留旧列表，不复用半完成结果。
