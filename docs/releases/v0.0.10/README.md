## 1. 版本结论

v0.0.8 只在 Changes 与 Commit 建立高效列表。本版本将成熟的路径详情、搜索、排序、选择摘要、键盘和小屏模式推广到其他真正需要的模块，消除同一手势在不同页面结果不同的问题。

推广不是“所有页面都套表格”：History 修订只能选择两条，Conflict 不能批量 Resolve，Agent 步骤和规则优先级不能任意排序，写操作预览不能在确认页重新勾选范围。

## 2. 共享契约

所有适用模块复用：

- v0.0.7 的项目、工作副本、仓库、scope 和双路径 identity；
- v0.0.8 的 PathCell、自然排序、搜索清除、结果数量、键盘导航和响应式布局；
- 相同的路径复制、Diff 打开、焦点恢复和读屏名称；
- 页面自己的排序、密度与列宽偏好；
- 同一列表内稳定的状态、空、失败、过期与恢复表达。

模块可以减少不适用能力，但不能让相同图标或快捷键产生不同含义。

## 3. Changelists

- 变更集与未分组文件的搜索和路径 / 状态排序；
- 手动多选、Shift 连续选择和“选择当前筛选”；
- “移入 / 移出变更集”批量预览；
- 已选路径批量复制、移除或打开 Diff；
- 分组折叠与筛选匹配数量；
- AI 或本地拆分建议保持其有意顺序，不套用文件表格排序。

真正应用 Changelist 继续经过 Host 预览与确认。

## 4. History

- 修订列表支持最新 / 最早排序和清除搜索；
- 两条比较选择显示摘要与清空；
- Changed Paths 支持路径搜索、操作类型筛选和路径 / 操作排序；
- 变更路径、复制来源和恢复目标复用路径详情；
- 修订比较固定选择 2 条，不提供全选修订。

## 5. Conflicts

- 路径、冲突类型和产生操作筛选；
- 路径 / 类型 / 来源排序；
- 上一个 / 下一个未解决冲突；
- 当前项目内路径、仓库内路径、工作副本定位和仓库定位；
- 当前冲突数量和处理进度。

Conflict 不提供“全选后解决”；每个 Resolve 继续单独预览、确认和复验。

## 6. Repository

### 6.1 Browser

- 从项目入口默认定位项目 URL；
- 面包屑同时标记项目根与 SVN 仓库根；
- 当前 URL 可选择、复制并明确向上浏览；
- 名称筛选，类型 / 名称 / 修订 / 作者 / 日期 / size 排序；
- 目录优先切换、文件复制 URL 与上下文菜单。

### 6.2 Properties 与写操作预览

- 属性名搜索、名称排序、复制属性名 / 值和完整目标路径；
- 属性编辑保持单项预览，不批量删除；
- Update、Patch、Shelf、恢复和高级操作的路径清单提供搜索、路径详情、复制清单和数量；
- 确认页文件集合不可二次勾选，修改范围必须返回上一步重新预览。

## 7. Settings 与 Diagnostics

- 提交选择规则预览支持路径搜索，决策 / 状态 / 来源筛选及稳定排序；
- 规则编辑继续按优先级手动上移 / 下移，明确“从上到下，首个命中生效”；
- Diagnostics 提供“只看需要处理”、状态筛选和复制单项；
- v0.0.7 的多根项目、工作副本与仓库归属在诊断中保持清晰。

## 8. AI Review、Impact、Agent 与 Diff 的过渡

在 v0.0.12 合并页面前：

- 本地 Review 支持标题、证据和路径搜索，严重度 / 分类筛选；
- Impact 支持风险 / 标题排序、影响路径搜索和路径详情；
- 两者只读，不为形式增加复选框；
- Agent 步骤保持审批顺序，禁止任意排序和全选批准；
- Diff 没有数据表，只复用路径详情、复制和仓库定位。

这些过渡改动应尽量使用共享组件，避免为即将合并的页面建立第二套复杂架构。

## 9. 可访问性与视口

- 所有页面覆盖键盘、触屏、读屏和中文 IME；
- 720×480、1024×600、1440×900 与 100%～200% 下主操作和恢复入口可达；
- Light、Dark、High Contrast 和 reduced motion 无信息丢失；
- 局部列表拥有明确滚动归属，无页面级横向滚动；
- 虚拟化、分组折叠和筛选后焦点、活动项与滚动锚点保持。

## 10. 实施顺序

1. 固化 v0.0.8 共享组件 API 与语义测试；
2. 依次迁移 Changelists、History、Conflicts；
3. 迁移 Repository Browser、Properties 和写操作预览清单；
4. 迁移 Settings 规则预览与 Diagnostics；
5. 只对 Review、Impact、Agent、Diff 做必要过渡复用；
6. 清理重复路径菜单与只依赖 `title` 的入口；
7. 运行候选验证并同步 `docs/current/`。

## 11. 候选验收

- `UX10-CONSIST-01`：相同路径、排序、搜索、复制和焦点手势跨模块结果一致；
- `UX10-CHG-01`：Changelist 可筛选多选并通过预览批量移动；
- `UX10-HIST-01`：History 只允许两个修订比较，Changed Paths 可搜索排序；
- `UX10-CONFLICT-01`：可快速定位未解决冲突，但不能批量 Resolve；
- `UX10-REPO-01`：Repository 面包屑区分项目根与仓库根，路径清单可操作；
- `UX10-PREVIEW-01`：写操作确认页不能扩大或二次改变 scope；
- `UX10-RULE-01`：规则预览可排序，规则执行优先级不被排序破坏；
- `UX10-A11Y-01`：所有迁移页面通过键盘、读屏、IME、200% 和 High Contrast 验收；
- `UX10-PERF-01`：共享组件不破坏模块懒加载和大列表预算。

人工主路径覆盖 Changelist 多选移动、History 比较、Conflict 单文件处理、Repository 浏览、Properties 预览、Update 预览、规则优先级和 Diagnostics 多根归属。

## 12. 明确不做

- 不给修订、Conflict Resolve、Agent 步骤或危险确认增加通用全选；
- 不让排序改变规则优先级、AI 有意排名或写操作步骤；
- 不在确认页重新定义范围；
- 不新增模型能力或外发数据；
- 不提前实现 v0.0.12 的完整变更解读；
- 不修改 `package.json` 版本，不生成发布 evidence。

## 13. 后续版本关系

- `v0.0.11` 复用这些路径、证据打开和草稿交互，提供有证据的提交说明；
- `v0.0.12` 复用同一底座完成变更解读、验证建议、语义拆分和冲突解释。
