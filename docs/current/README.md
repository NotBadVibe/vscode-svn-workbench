# 当前基线

本目录描述 `v0.0.3` 发布线当前应遵守的产品与工程规则，不等同于某次发布验收结果。

- [`产品与功能基线.md`](./产品与功能基线.md)：能力范围、优先级和完成标准。
- [`设计与交互基线.md`](./设计与交互基线.md)：中文体验、页面结构、滚动与可访问性规则。
- [`实现与代码映射.md`](./实现与代码映射.md)：领域契约、主要代码位置和测试映射。
- [`测试与验收基线.md`](./测试与验收基线.md)：质量层级、交付门禁和证据规则。
- [`prototypes/`](./prototypes/)：用于浏览设计表面的当前原型，不承担版本证明作用。

优先级冲突时依次采用：实际代码与测试契约、当前基线、已发布版本记录、历史归档。
