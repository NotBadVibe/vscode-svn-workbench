# SVN Workbench 文档中心

文档只保留三种身份，避免原型编号、日期和扩展版本互相混用。

| 区域                       | 权威性   | 用途                                         |
| -------------------------- | -------- | -------------------------------------------- |
| [`current/`](./current/)   | 当前基线 | 当前产品、交互、实现和测试规则               |
| [`releases/`](./releases/) | 版本事实 | 按 SemVer 固化源码、产物、测试和截图         |
| [`archive/`](./archive/)   | 历史参考 | 旧原型、候选版本和研发里程碑，不代表当前实现 |

## 维护规则

1. 当前规范只写入 `current`，不在目录名中加入原型代号或日期。
2. 一个版本只占一个 `releases/vX.Y.Z` 目录；发布后不可覆盖其证据。
3. 普通测试写入 `.validation/evidence`，只有显式发布证据命令可以写入 `docs/releases`。
4. 每次改动功能、测试或证据路径后执行 `npm run docs:verify`。
5. 历史结论引用时必须标注其版本或日期，不可作为当前通过状态。
